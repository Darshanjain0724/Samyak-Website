# Figma Fidelity Checklist

## Content

- [ ] Every visible Figma text exists.
- [ ] No extra visible text exists.
- [ ] Text matches exactly.

## Assets

- [ ] Exact logo used.
- [ ] Exact images used.
- [ ] Exact SVGs used.
- [ ] Exact icons used.
- [ ] No icon-library substitutions.
- [ ] No placeholder assets.

## Layout

- [ ] Frame dimensions match.
- [ ] Container dimensions match.
- [ ] Padding matches.
- [ ] Margins match.
- [ ] Gaps match.
- [ ] Alignment matches.
- [ ] Positioning matches.

## Typography

- [ ] Font family matches.
- [ ] Font size matches.
- [ ] Weight matches.
- [ ] Line height matches.
- [ ] Letter spacing matches.

## Visuals

- [ ] Colors match.
- [ ] Borders match.
- [ ] Radius matches.
- [ ] Shadows match.
- [ ] Opacity matches.

## Validation

- [ ] Application rendered.
- [ ] Correct viewport used.
- [ ] Screenshot captured.
- [ ] Compared with Figma.
- [ ] Discrepancies corrected.
- [ ] Final comparison performed.
